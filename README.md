# 방과 후의 교실 — 비주얼 노벨 틀

코딩 없이 **`story.js` 한 파일만 고치면** 게임이 만들어지는 비주얼 노벨 엔진입니다.
폰 세로 화면 / PC 가로 화면 모두 지원해요.

## 파일 구성
| 파일 | 역할 |
|---|---|
| `story.js` | ✏️ **스토리, 캐릭터, 배경 목록** — 여기만 고치면 됨 |
| `engine.js` | 게임 엔진 (수정 불필요) |
| `index.html` | 화면 디자인 |
| `images/bg/` | 배경 이미지 |
| `images/char/` | 캐릭터 이미지 (배경 투명 PNG) |

## 기능
- 타이핑 효과 대사 / 나레이션, 이름표 색상
- 캐릭터 표정 변경, 좌·중·우 배치, 말하는 캐릭터 강조
- 선택지 · 변수(호감도 등) · 조건 분기 · 멀티 엔딩
- 저장/불러오기 6슬롯, 대사 로그, 자동 진행, 스킵, 글자 속도 설정
- 화면 흔들기, 번쩍임, 페이드 연출
- 본 엔딩 기록 (타이틀 화면에 표시)

## 스토리 쓰는 법 (story.js)
```js
"그냥 문장"                       // 나레이션
"하루: 안녕?"                     // 대사
{ bg: "classroom" }               // 배경 변경
{ show: "haru", face: "smile" }   // 캐릭터 등장/표정 (normal, smile, pout, shy)
{ hide: "haru" }                  // 퇴장
{ choice: [ { text: "보기", goto: "장면", set: { 호감도: +1 } } ] }
{ if: "호감도 >= 2", goto: "좋은엔딩", else: "보통엔딩" }
{ end: "엔딩 이름" }
```
