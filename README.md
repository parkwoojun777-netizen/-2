# 노벨 공방 — 비주얼 노벨 창작기 + 엔진

폰만으로 비주얼 노벨을 만들고, 만든 내용을 코드로 보면서 자바스크립트를 배울 수 있는 도구예요.

## 파일
| 파일 | 역할 |
|---|---|
| `editor.html` · `editor.js` · `editor.css` | ✏️ 창작기 (블록으로 스토리 만들기) |
| `engine.js` | 🛠 게임 엔진 — `VN.mount(요소, PROJECT)` |
| `story.js` | 📖 샘플 게임 「방과 후의 교실」 (주인공: 샬럿) |
| `index.html` | ▶ 샘플 게임 실행 화면 |
| `images/` | 배경과 캐릭터 그림 |

## 창작기 기능
- **스토리**: 장면을 만들고 블록을 쌓아요 — 대사, 나레이션, 배경, 이벤트 그림, 변수 그림, 캐릭터 등장/퇴장, 선택지, 변수, 조건 분기, 장면 이동, 효과, 입자 효과 16가지(벚꽃·낙엽·눈·비·폭우+번개·물방울·안개·수증기·진한 연기·불티·반짝이·반딧불·빛·거품·하트·꽃가루), 화면 색감, 미니게임, 엔딩
- **미니게임**: 일러스트 위에 오브젝트를 놓고, 플레이어가 고른 오브젝트에 따라 변수가 바뀌어요 (숨은 오브젝트 가능)
- **회상방**: 본 이벤트 그림, 다시 볼 장면, 엔딩 모음
- **게이지**: 숫자 변수를 게이지로 보여줘요 — 가로 막대 · 세로 통(탱크) · 동그라미 · 아이콘 여러 개 · 배터리 칸, 위치 · 크기 · 숫자(값/%)/100% 넘기기, 눈금, 경고 표시점(닿으면 색 바꾸기 · 흔들기 · 번쩍), 미리보기
- **입자 방향 · 내 효과**: 효과가 나오는 방향과 퍼지는 폭을 고르고, 모양 · 색 · 크기 · 빠르기 · 중력 · 투명도 · 나타나는 시간 · 서서히 사라지는 정도 · 크기 변화 · 회전까지 정한 나만의 입자 효과를 미리보기로 만들어요. 계속 나오는 효과는 여러 개를 같이 켤 수 있어요. 미리보기 배경(내 배경 · 이벤트 그림 · 검은/흰 화면)과 캐릭터 같이 보기를 고를 수 있고, 고른 것은 기억돼요
- **CG 넘기기 · 효과음**: 탭할 때마다 이벤트 그림이 부드럽게 바뀌면서 대사 · 효과음 · 효과(흔들기 · 번쩍 · 입자)가 나와요. 효과음 파일을 올려 [효과음] 블록으로도 쓸 수 있어요
- **배경음악 · 캐릭터 움직임**: 음악을 반복 재생하고 서서히 바꾸거나 끄고(타이틀 음악 · 저장 후 이어 듣기 · 따로 볼륨), 캐릭터를 깡총 · 끄덕 · 도리도리 · 깜짝 (한 번), 덜덜 · 부들부들 · 숨쉬기 · 둥실 (계속), 살짝 아래로 · 주저앉기 · 다가오기 · 멀어지기 · 기울이기 · 반투명 (자세) 로 움직여요. 대사 블록에서 말하면서 움직일 수도 있어요
- **📥 보관함**: 사진첩이 안 열리는 화면(앱 안 브라우저 등)에서도 그림 · 소리를 넣을 수 있게, 채팅으로 받은 파일을 `inbox/` 에 넣어 두면 모든 [사진첩에서 고르기] 옆 [📥 보관함에서 고르기]로 가져와요
- **🧩 변수 그림 (화면 위 그림)**: 변수 그림 전용 업로드 칸에 올린 그림을 화면 어디에든 띄워요 — 위치(눌러서 고르기) · 크기 · 층(캐릭터 뒤/앞/맨 앞) · 나타나기(서서히 · 톡 · 떨어지기 · 밀려오기) · 자리 이름으로 여러 장 동시에
- **⚡ 시그널**: 이름 붙인 블록 묶음을 만들어 두고 [시그널 보내기] 블록 · 선택지 · 게이지 표시점 · 자동 조건(예: 호감도 4 이상이 되는 순간)으로 실행해요. 끝나면 보낸 곳으로 돌아가요
- **묶음 · 복사 · 붙여넣기**: 여러 블록을 골라 묶음으로 정리하고, 다른 장면이나 작품에 복사해 붙여넣을 수 있어요
- **그림**: 배경과 캐릭터 표정을 올려요. 캐릭터 그림의 흰 배경은 자동으로 지울 수 있어요
- **변수**: 호감도 같은 숫자, 글자, 참/거짓 값을 만들어요
- **코드**: 만든 게임이 코드로 어떻게 생겼는지 보고, 직접 고쳐서 적용할 수 있어요. 코드 기초 강의 6개 포함
- **테스트**: 처음부터 또는 지금 장면부터 바로 플레이해요
- **내보내기**: 혼자 열리는 게임 파일(.html), 안드로이드 앱(.apk), 백업(.json)을 저장해요
- **장면 나누기 · 분기 만들기 · 장면 지도**: 블록에서 장면을 둘로 나누고, 선택지나 변수로 갈래 · 엔딩을 한 번에 만들고, 장면이 어떻게 이어지는지 지도로 봐요
- 문제 찾기: 없는 장면으로 가는 이동이나 끝이 없는 장면을 알려줘요

## 게임 데이터 형식 (PROJECT)
```js
const PROJECT = {
  title: "게임 제목", start: "프롤로그",
  vars: { 호감도: 0 },
  backgrounds: { classroom: "images/bg/classroom.jpg" },
  characters: { charlotte: { name: "샬럿", color: "#8fd3ff", faces: { normal: "..." } } },
  story: {
    프롤로그: [
      { bg: "classroom" },
      "샬럿: 안녕?",
      { choice: [{ text: "안녕", goto: "다음", set: { 호감도: +1 } }] },
    ],
  },
};
```
블록 문법은 `story.js` 위쪽 설명을 참고하세요.

## 웹에서 열기
GitHub **Settings → Pages** 에서 이 브랜치를 고르면 `.../editor.html`(창작기)과 `.../index.html`(샘플 게임)을 폰에서 열 수 있어요.

## 샘플 앱
`dist/방과 후의 교실.apk` — 샘플 게임을 안드로이드 앱으로 만든 것 (안드로이드 7.0 이상)
