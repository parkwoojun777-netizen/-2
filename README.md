# 서하의 월요일 (프로토타입)

선택지에 따라 내용이 바뀌는 캠퍼스 일상 비주얼 노벨. 브라우저에서 `index.html`을 열면 바로 실행된다 (빌드 과정 없음).

## 조작
- 클릭 / Space / Enter: 진행 (글자 출력 중이면 즉시 완성)
- Ctrl 누르고 있기: 스킵 · A: 자동 진행 · H: UI 숨기기 · L 또는 휠 위로: 로그
- 선택지: 클릭 또는 숫자 키 1~3
- 저장 슬롯 3개 + 자동 저장(선택지마다)

## 구조
- `js/story.js` — 스토리 스크립트 (캐릭터·배경·엔딩 정의 포함). 명령 형식은 파일 상단 주석 참고
- `js/engine.js` — 엔진 (대사 타이핑, 선택지, 변수/분기, 배경·표정 전환, 저장/불러오기, 로그)
- `assets/characters/` — 투명 배경 캐릭터 스프라이트 (normal / pout / uneasy / wink)
- `assets/bg/` — 배경 SVG (`python3 tools/make_bg.py`로 재생성)
- `tools/remove_bg.py` — 흰 배경 일러스트를 투명 PNG로 변환

## 현재 분기
호감도(`aff`)에 따라 엔딩 3종: 좋음(5 이상) / 보통(1 이상) / 나쁨.
